# Проект Serch_for_vacancies_BD

## Описание проекта:

Проект Serch_for_vacancies_BD - предназначен для получения вакансий с Head Haunter, для отрабатывания навыков работы с классами.

##  Установка

1. Клонируйте репозиторий:
```
git@github.com:olgakostenko240/Search_for_vacancies_BD.git
```

2. Установите зависимости:
```
poetry install
```

3. Установите библиотеку psycopg2:
```
poetry add psycopg2
```

## Использование:

1. Создан класс HeadHunterAPI для подключения и получения данных с сайта Head Haunter.
2. Создан класс Vacancy для создания и заполнения таблиц в базе данных.
3. Создан класс DBManager для работы с таблицами в базе данных.
